# 🏍 قطعات یدکی موتور سیکلت پالس - سیستم حسابداری

سیستم حسابداری پیشرفته برای مدیریت قطعات یدکی موتور سیکلت پالس با Google Apps Script

## ✨ ویژگی‌ها

- 📊 **داشبورد مالی** - نمایش آمار و اطلاعات لحظه‌ای
- 📝 **مدیریت اسناد** - ثبت، ویرایش و حذف اسناد مالی
- 🔍 **جستجوی پیشرفته** - جستجو در تمام بخش‌ها
- 📱 **طراحی واکنش‌گرا** - نمایش بهینه در موبایل و دسکتاپ
- 🌙 **دارک مود** - طراحی مدرن و چشم‌نواز
- 💾 **ذخیره در Google Sheets** - استفاده از Google Sheets به عنوان دیتابیس

## 🚀 نصب و راه‌اندازی

1. یک Google Spreadsheet جدید ایجاد کنید
2. از منوی Extensions → Apps Script را باز کنید
3. فایل‌های زیر را کپی کنید:
   - `Code.gs` - کد بک‌اند
   - `Index.html` - رابط کاربری
   - `CSS.html` - استایل‌ها
4. از منوی Deploy → New deployment را انتخاب کنید
5. نوع Web app را انتخاب و Deploy کنید
6. آدرس URL را باز کنید

## 📁 ساختار شیت‌ها

| شیت | نام | ستون‌ها |
|-----|-----|---------|
| M1 | دفتر معین | دفتر معین |
| T1 | دفتر تفصیلی | دفتر معین، دفتر تفصیلی، ملاحظات |
| S1 | اسناد | شماره سند، تاریخ، عنوان معین، عنوان تفصیلی، بدهکار، بستانکار، شرح |

## 🛠 تکنولوژی‌ها

- Google Apps Script
- HTML5 / CSS3
- JavaScript (ES6+)
- Google Sheets API
